# evonymasters

An independent Evony: The King's Return monster finder. The website will show verified monster information, stamina, power, and guaranteed versus possible rewards.

## Initial setup

The repository is initialized. To add the starter source, download `evonymasters-starter.zip` from the ChatGPT conversation, extract it, and upload the **contents of the `evonymasters` folder** to this repository (not the ZIP itself). Replace this README with the starter README when uploading.

After the source is committed, GitHub Actions will validate data, run tests, check Astro, and build the site. Then connect this repository to Cloudflare Pages with build command `npm run build` and output directory `dist`.

Monster data starts empty until verified. Do not commit `.env` or secrets.
